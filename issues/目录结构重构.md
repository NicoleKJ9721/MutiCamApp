# 目录结构重构计划

## 重构目标
将src/目录下散乱的文件按功能模块重新组织，提高代码可维护性。

## 新目录结构
```
src/
├── core/              # 核心应用逻辑
│   ├── MutiCamApp.cpp/h
│   └── main.cpp
├── ui/                # 用户界面组件
│   ├── CalibrationDialog.cpp/h
│   ├── CheckerboardCalibrationDialog.cpp/h
│   ├── TemplateSelectionDialog.cpp/h
│   ├── VideoDisplayWidget.cpp/h
│   ├── ZoomPanWidget.cpp/h
│   ├── PaintingOverlay.cpp/h
│   └── MutiCamApp.ui
├── utils/             # 工具类
│   ├── LogManager.cpp/h
│   ├── SettingsManager.cpp/h
│   ├── SerialController.cpp/h
│   ├── TrajectoryRecorder.cpp/h
│   └── dependencies_test.cpp/h
├── camera/            # 相机模块（保持不变）
├── image_processing/  # 图像处理（保持不变）
└── matching/          # 匹配算法（保持不变）
```

## 执行步骤
1. 创建新目录：core/, ui/, utils/
2. 移动文件到对应目录
3. 更新CMakeLists.txt中的文件路径
4. 更新所有源文件中的#include路径
5. 验证编译配置

## 预期效果
- 根目录文件从22+个减少到3个目录
- 按功能职责清晰分离
- 提高代码组织性和可维护性
