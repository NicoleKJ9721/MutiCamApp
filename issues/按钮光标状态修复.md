# ROI 按钮光标状态修复

## 问题描述
ROI 按钮（√×）在鼠标移入时正确显示手型光标，但移出按钮区域后光标没有恢复为默认箭头光标，保持手型状态。

## 问题根因分析

### 控制点正常工作的原因
- 使用 `m_hoverHandle` 状态跟踪变量
- `getROIHandleAt()` 返回 `NoHandle` 时，`updateROICursor(NoHandle)` 在 `default` 分支设置 `Qt::ArrowCursor`
- 只在状态改变时更新光标：`if (hoverHandle != m_hoverHandle)`

### 按钮异常的原因
- 按钮检测在控制点检测之前执行
- 鼠标从按钮移出到空白区域时，`m_hoverHandle` 可能已经是 `NoHandle`
- 条件 `hoverHandle != m_hoverHandle` 为 false，不会调用 `updateROICursor` 恢复箭头光标

## 解决方案
添加按钮状态跟踪，与控制点使用相同的状态管理模式。

### 修改内容

#### 1. 头文件修改 (PaintingOverlay.h)
在 ROI 创建模式相关成员变量后添加：
```cpp
bool m_isHoveringButton;          // 是否悬浮在ROI按钮上（用于光标状态管理）
```

#### 2. 构造函数初始化 (PaintingOverlay.cpp)
在初始化列表中添加：
```cpp
, m_isHoveringButton(false)
```

#### 3. 鼠标移动事件逻辑修改 (PaintingOverlay.cpp)
替换原有的按钮光标处理逻辑：

**原逻辑：**
```cpp
bool isConfirm;
if (isPointInROIButton(imagePos, isConfirm)) {
    setCursor(Qt::PointingHandCursor);
} else {
    // ROI控制点处理...
}
```

**新逻辑：**
```cpp
bool isConfirm;
bool currentlyHoveringButton = isPointInROIButton(imagePos, isConfirm);

if (currentlyHoveringButton != m_isHoveringButton) {
    m_isHoveringButton = currentlyHoveringButton;
    if (m_isHoveringButton) {
        setCursor(Qt::PointingHandCursor);
    } else {
        // 鼠标移出按钮区域，检查ROI控制点状态
        PaintingOverlay::ROIObject::HandleType hoverHandle = getROIHandleAt(imagePos);
        m_hoverHandle = hoverHandle;
        updateROICursor(hoverHandle);
    }
} else if (!m_isHoveringButton) {
    // 不在按钮上时，正常处理ROI控制点悬停
    PaintingOverlay::ROIObject::HandleType hoverHandle = getROIHandleAt(imagePos);
    if (hoverHandle != m_hoverHandle) {
        m_hoverHandle = hoverHandle;
        updateROICursor(hoverHandle);
    }
}
```

## 核心改进
1. **状态跟踪**：添加 `m_isHoveringButton` 跟踪按钮悬浮状态
2. **状态比较**：只在按钮悬浮状态改变时更新光标
3. **统一管理**：按钮和控制点使用相同的状态管理模式
4. **正确恢复**：移出按钮时强制检查控制点状态并更新光标

## 修复结果
- 鼠标移入按钮：显示手型光标
- 鼠标移出按钮：正确恢复为箭头光标或相应的控制点光标
- 与控制点光标管理保持一致的行为模式
